# Contributing

Any kind of contribution is welcome!

I'm open to help in any form, whether it's reporting bugs, suggesting improvements, discussing ideas, improving documentation, or contributing code.

You don't need to make a large contribution. Feedback, questions, and suggestions are just as welcome.

## How to contribute

- **Report bugs:** Open an issue describing the problem.
- **Suggest improvements:** Share ideas for new features or changes.
- **Improve documentation:** Help make the project easier to understand and use.
- **Contribute code:** Submit a pull request with your changes.
- **Share feedback:** Any feedback that can help improve the project is appreciated.

If you have an idea or want to help in another way, feel free to open an issue or start a discussion.

Thank you for taking the time to contribute!
