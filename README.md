# Journal API

A Python tool for interacting with my college's journal API.

The project provides a way to send requests to the college journal system through its API. It was developed as a personal learning project to practice Python and working with REST APIs.

## About

Journal API is a Python-based tool for communicating with an existing college journal system through its API.

The project focuses on API interaction and provides a foundation for working with data exposed by the college's journal service.

## Tech stack

- Python
- REST API

## Getting started

### Prerequisites

- Python
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/lenseps/python-journal-api.git
   cd python-journal-api
   ```

2. Create a virtual environment:

   ```bash
   python -m venv .venv
   ```

3. Activate the virtual environment.

   **Windows:**

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   **Linux / macOS:**

   ```bash
   source .venv/bin/activate
   ```

4. Install the dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Run the application using its configured entry point.

## Project status

This project is developed for personal use and educational purposes. It is a tool for interacting with an existing college journal API, not a standalone journal system.
